Decormate AR

Visualization app for multi-object interior decor

Aug – Nov 2024 — serves shoppers placing furniture, decor and lab equipment in real rooms

Ingredients

  • C#
  • Unity 2022.3
  • AR Foundation
  • Unity Addressables
  • ARBaseGestureInteractable
  • DOTween

Method

  1. Raycast from the centre of the screen against detected planes, and drive a crosshair to the hit pose so the user always sees where an object will land.
  2. Load the furniture catalogue asynchronously through Addressables, so the app does not carry every 3D model in its initial build.
  3. Parent each placed object to its own anchor rather than a shared root, which is what allows several objects to persist independently in one scene.
  4. Reject placements whose surface normal faces away from the camera, using a dot product against the hit pose, to stop objects appearing behind walls.
  5. Guard every placement tap with a UI raycast test, so tapping the catalogue never drops furniture into the room by accident.

Yield

  • Copyright SW-20059/2025 Registered with the Government of India, 8 Jan 2025
  • 60+ fps on device Sustained with multiple models placed
  • Multi-object placement Independent anchors per object

Respiratory disease detection

Chest X-ray classification with a ResNet-based CNN

Feb – Apr 2025 — serves clinicians triaging chest X-rays where a radiologist is not on hand

Ingredients

  • Python
  • ResNet
  • Deep learning
  • Medical imaging datasets

Method

  1. Assemble and clean chest X-ray datasets covering pneumonia, tuberculosis and COVID-19.
  2. Build a preprocessing and augmentation pipeline so the model generalises across images from different machines and hospitals.
  3. Train a ResNet-based classifier and validate it against held-out data.
  4. Evaluate on accuracy, precision, recall and F1 rather than accuracy alone, because class imbalance makes accuracy misleading here.

Yield

  • Published, ICAIEHS-2025 DOI 10.2991/978-94-6463-852-3_19
  • Three-class classifier Pneumonia, tuberculosis, COVID-19
